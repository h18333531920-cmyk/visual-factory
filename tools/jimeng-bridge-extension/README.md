# GCC Design · 即梦本机桥（Chrome / Edge）

这是一个**本机加载的浏览器扩展**。它只在用户主动选择、且已登录的即梦标签页中执行操作；不会保存即梦账号密码，也不会在后台自行发起生成。

## 安装（开发者模式）

1. 在 Chrome 打开 `chrome://extensions`；在 Edge 打开 `edge://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件所在的文件夹：`tools/jimeng-bridge-extension`。
5. 在浏览器中登录并打开 `https://jimeng.jianying.com/` 的“生成”页面。
6. 点击浏览器工具栏中的“GCC Design · 即梦本机桥”，选择要连接的即梦标签页。
7. 回到 GCC Design，生图卡片选择“即梦本机”，输入提示词/添加参考图后点击生成。

生成会在已配对的即梦标签页进行。结果出现在页面上后，保持该标签页为当前激活标签页，回到 DIY 点击“导入结果”即可将当前可见结果截图裁切后放入画板。

## 当前限制

- 即梦网页没有为本机自动化提供稳定公开接口，网页改版后可能需要调整 `jimeng-bridge.js` 内的选择器。
- 导入采用浏览器截图裁切，因此先用于验证链路和工作流；它不是原始无损文件下载。后续可根据即梦实际结果页的下载/资源地址再做无损导入。
- 只支持 Chrome / Edge；Safari、Firefox 需要各自的扩展版本。
